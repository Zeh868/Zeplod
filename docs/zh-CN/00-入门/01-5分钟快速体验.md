# 5 分钟快速体验

**目标**：在已经可用的 Zephyr 4.3.x 环境中，用 5 分钟构建并运行 Zeplod，无需开发板。

> 若尚未安装 Zephyr、SDK、West 和依赖，请先完成[环境搭建与配置指南](../10-环境与构建/11-环境搭建与配置指南.md)。
> 首次安装通常需要下载较多内容，不计入本页的 5 分钟。

## 前置检查

```bash
python --version
west --version
cmake --version
```

还需要满足以下任一路径：

- **Linux / WSL2（推荐）**：使用 Zephyr 的 `native_sim` 板型。
- **Windows 原生**：已安装 QEMU；使用仓库脚本和 `qemu_riscv32`。
- **macOS**：已安装 QEMU；使用 `qemu_riscv32`。macOS 与 Windows 原生均不支持 `native_sim` / `native_posix`。

## 第 1 步：获取代码

```bash
git clone https://github.com/QZehao/Zeplod.git
cd Zeplod
```

若已经在仓库中，直接进入下一步。

## 第 2 步：配置本地路径

从模板创建本地配置，并填写本机 Zephyr 和 SDK 路径：

```powershell
# Windows PowerShell
Copy-Item zephyr_config.env.template zephyr_config.env
.\scripts\setup_env.ps1
```

```bash
# Linux / macOS / WSL
cp zephyr_config.env.template zephyr_config.env
# 编辑 zephyr_config.env 后加载
source scripts/setup_env.sh
```

`zephyr_config.env` 是本机文件，不应提交。当前仓库历史中若仍跟踪该文件，请以模板为准并等待仓库维护者清理。

## 第 3 步：构建并运行

### Linux / WSL2：native_sim

```bash
west build -b native_sim . -p always
west build -t run
```

### Windows 原生：QEMU

```powershell
.\scripts\run_qemu.ps1 -Board qemu_riscv32
```

脚本会使用 `prj.conf;conf/targets/qemu.conf` 构建并启动 QEMU。更多板型和参数见
[QEMU 仿真运行指南](../10-环境与构建/14-QEMU仿真运行指南.md)。

### macOS：QEMU

```bash
west build -b qemu_riscv32 -d build_qemu . -p always -- \
  -DCONF_FILE="prj.conf;conf/targets/qemu.conf"
west build -t run --build-dir build_qemu
```

构建成功时 West 会显示构建完成；启动后应看到 Zephyr 启动信息、Zeplod Banner 和 Shell 提示符。
具体提交哈希、时间和日志级别随本机构建变化，因此本页不固定伪造的完整输出。

## 第 4 步：查看运行状态

在 Shell 中执行：

```text
app status
app modules
app events
app help
version
```

这些命令分别显示应用状态、已注册模块、事件统计、帮助和版本构建信息。

## 你刚刚验证了什么？

- Zephyr、SDK、West 与本仓库路径配置可用。
- 应用能够为主机仿真或 QEMU 完成配置、编译和链接。
- Zeplod 的自动初始化链和 Shell 已启动。

这不是硬件验证。外设、烧录、RAM 布局和板级 overlay 仍需在目标板上单独验证。

## 常见问题

**`west` 或 SDK 找不到**：返回环境搭建指南核对虚拟环境、`ZEPHYR_BASE` 和 `ZEPHYR_SDK_INSTALL_DIR`。

**Windows 或 macOS 提示 POSIX 板不能运行**：不要强制使用 `native_sim` / `native_posix`；改用本页的 QEMU 命令，Windows 也可转到 WSL2。

**配置修改后行为未变化**：使用 `-p always`，或先执行 `west build -t pristine` 再构建。
